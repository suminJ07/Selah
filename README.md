
# Selah 🎵

**음악의 시작과 끝을 더 부드럽게.**

Selah는 YouTube 영상을 이용해 음악을 재생하고, 페이드 인(Fade In)과 페이드 아웃(Fade Out)을 간편하게 제어할 수 있는 웹 기반 음악 컨트롤러입니다.

복잡한 오디오 프로그램 없이 YouTube 링크 하나만으로 음악을 준비하고, 버튼 한 번으로 자연스럽게 음악을 시작하거나 종료할 수 있습니다.

별도의 프로그램 설치나 회원가입 없이 웹 브라우저에서 사용할 수 있습니다.

## ✨ 주요 기능

### 1. YouTube 음악 재생
- YouTube 영상 URL을 입력해 음악 불러오기
- 플레이어에서 영상 확인 및 재생
- 일반 YouTube 링크, 단축 링크, Shorts 및 Live 링크 지원
- 별도의 음원 파일 다운로드 불필요

### 2. 페이드 인 (Fade In)
- 음악 시작 시 볼륨을 서서히 높이는 기능
- 페이드 인 시간: **3초 고정**
- 체크박스로 사용 여부 선택
- 기본 설정: 사용 안 함
- 일시정지 후 재개할 때는 페이드 인을 다시 적용하지 않음

### 3. 페이드 아웃 (Fade Out)
- 버튼 한 번으로 음악 볼륨을 자연스럽게 감소
- **3초 / 4초 / 5초** 중 원하는 시간 선택
- 페이드 아웃 완료 시 볼륨 0%, 음소거 및 재생 일시정지
- 페이드 인 진행 중에도 페이드 아웃 실행 가능

### 4. 볼륨 조절
- 슬라이더로 시작 볼륨 설정
- 0~100% 범위 조절
- 기본 볼륨: 70%
- 설정한 볼륨을 브라우저에 저장

### 5. 하단 고정 컨트롤
- 창을 작게 띄우거나 스크롤해도 주요 조작 영역 유지
- 음악 재생 상태 확인
- 페이드 인 사용 여부 설정
- 시작 볼륨 및 페이드 아웃 시간 변경
- 음악 시작 / 음악 종료 버튼 제공

### 6. 실시간 상태 알림
- 음악 대기 중
- 음악 준비 완료
- 음악 재생 중
- 페이드 아웃 중
- 음악 종료 완료
- 오류 발생

오류 발생 시 **자세히 보기**를 통해 원인, 해결 방법 및 오류 코드를 확인할 수 있습니다.

### 7. 라이트 / 다크 모드
- 라이트 모드와 다크 모드 지원
- 첫 방문 시 시스템 테마 설정 적용
- 아이콘 버튼으로 테마 전환
- 사용자가 선택한 테마를 브라우저에 저장

### 8. 설정 자동 저장
브라우저의 Local Storage를 이용해 다음 설정을 저장합니다.

- 마지막으로 입력한 YouTube URL
- 시작 볼륨
- 페이드 아웃 시간
- 페이드 인 사용 여부
- 사용자가 선택한 테마

별도의 계정이나 서버 데이터베이스가 필요하지 않습니다.

## 🚀 사용 방법

1. Selah 웹페이지에 접속합니다.
2. YouTube 영상 URL을 입력합니다.
3. **불러오기** 버튼을 눌러 영상을 준비합니다.
4. 필요하면 페이드 인 사용 여부와 시작 볼륨을 설정합니다.
5. **음악 시작** 버튼을 눌러 재생합니다.
6. 음악을 종료하고 싶을 때 **음악 종료** 버튼을 누릅니다.
7. 선택한 페이드 아웃 시간에 따라 볼륨이 감소한 뒤 재생이 일시정지됩니다.

> 페이드 인은 기본적으로 비활성화되어 있으며, 활성화하면 음악을 처음 시작할 때 3초 동안 볼륨이 서서히 증가합니다.

## 🛠 기술 스택

| 구분 | 기술 |
| --- | --- |
| 구조 | HTML5 |
| 스타일 | CSS3 |
| 기능 구현 | Vanilla JavaScript |
| 영상 재생 | YouTube IFrame Player API |
| 설정 저장 | Web Storage API (Local Storage) |
| 배포 | GitHub Pages |

Selah는 별도의 프레임워크나 빌드 도구 없이 하나의 `index.html` 파일로 실행되는 웹 애플리케이션입니다.

---

## 📁 프로젝트 구조

```text
selah/
├── index.html
└── README.md
```

- `index.html`: 화면 구성, 스타일, 음악 제어 로직
- `README.md`: 프로젝트 소개 및 사용 안내

---

## 💻 로컬 실행

1. 저장소를 다운로드하거나 복제합니다.
2. `index.html` 파일을 웹 브라우저에서 실행합니다.
3. YouTube URL을 입력해 음악을 불러옵니다.

YouTube 플레이어가 정상적으로 작동하려면 인터넷 연결이 필요합니다.

일부 브라우저 환경에서는 로컬 파일(`file://`) 실행 시 YouTube 플레이어가 제한될 수 있으므로, HTTP 서버 또는 GitHub Pages 환경에서 사용하는 것을 권장합니다.

---

## 🌐 GitHub Pages 배포

1. GitHub 저장소에 `index.html`을 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
4. 배포 브랜치와 `/ (root)` 경로를 선택합니다.
5. 저장 후 생성된 GitHub Pages 주소로 접속합니다.

별도의 서버 구축 없이 정적 웹사이트로 배포할 수 있습니다.

## ⚠️ 사용 시 주의사항

### YouTube 광고
Selah는 YouTube IFrame Player API를 사용합니다.

YouTube 광고를 직접 차단하거나 건너뛰는 기능은 제공하지 않습니다. 재생 중 광고가 표시될 수 있습니다.

### 외부 사이트 재생 제한
일부 YouTube 영상은 업로더의 설정 또는 YouTube 정책에 따라 외부 웹사이트에서 재생되지 않을 수 있습니다.

이 경우 다른 영상을 사용해야 합니다.

### 볼륨 제어 범위
Selah의 볼륨 제어는 **Selah에서 재생하는 YouTube 플레이어에만 적용**됩니다.

컴퓨터 전체의 시스템 볼륨이나 다른 프로그램에서 재생되는 소리는 제어하지 않습니다.

### 브라우저 재생 제한
브라우저 정책에 따라 사용자 조작 없이 음악을 자동으로 재생하는 기능이 제한될 수 있습니다.

Selah는 사용자가 직접 음악 시작 버튼을 눌러 재생하는 방식입니다.

### 인터넷 연결
YouTube 영상을 재생하므로 인터넷 연결이 필요합니다.

## 📌 향후 검토 기능

다음 기능들은 현재 구현되지 않았으며, 향후 필요에 따라 검토할 예정입니다.

- 로컬 MP3 등 오디오 파일 재생
- 인터넷 연결 없이 사용할 수 있는 음악 재생 방식
- 추가적인 음악 제어 편의 기능

Selah는 복잡한 기능을 늘리기보다 **간단하고 안정적인 음악 제어 경험**을 유지하는 것을 목표로 합니다.

## 📄 라이선스

현재 별도의 오픈소스 라이선스가 지정되어 있지 않습니다.

YouTube 영상과 음원의 저작권은 각 권리자에게 있으며, Selah를 이용한 음악 재생 시 해당 콘텐츠의 이용 조건을 준수해야 합니다.
